# @identvia/js

Sign in with Identvia: browser SPA client plus Node/Express/Next.js server helpers. See the [repository README](../../README.md) for quickstarts.

* `import { IdentviaClient } from '@identvia/js'`: browser (public client)
* `import { IdentviaServerClient, IdentviaAuth } from '@identvia/js/server'`: any server runtime
* `import { identvia } from '@identvia/js/express'`
* `import { createIdentviaNext } from '@identvia/js/next'`

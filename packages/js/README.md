# @identvia/js

[![npm](https://img.shields.io/npm/v/@identvia/js)](https://www.npmjs.com/package/@identvia/js)

```bash
npm install @identvia/js
```

Sign in with Identvia: browser SPA client plus Node/Express/Next.js server helpers. See the [repository README](https://github.com/Identvia/identvia-js#readme) for quickstarts.

* `import { IdentviaClient } from '@identvia/js'`: browser (public client)
* `import { IdentviaServerClient, IdentviaAuth } from '@identvia/js/server'`: any server runtime
* `import { identvia } from '@identvia/js/express'`
* `import { createIdentviaNext } from '@identvia/js/next'`
